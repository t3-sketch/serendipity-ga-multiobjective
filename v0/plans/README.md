# v0の実験計画

現行v0-S1（MovieLens 1M baseline）は事後整理である。
旧100Kのv0-S1〜S3はGit historyに残し、1Mの事前計画や完了実験として転用しない。
当時の独立した事前計画書と承認の対応は未確認であり、過去の結果から事前計画を作り直さない。
実施条件は各[report](../ROADMAP.md)と保存済みconfigを参照する。

未実施のStepを始める際にだけ`Sxx-名前.md`を作る。
次の項目を一つのファイルに記す。

## 記入する項目

- ID、関連Macro、作成日、状態（草案／承認済み／実施中／完了／保留）
- RQ、課題、仮説、根拠、反証条件
- 固定する条件と変更する条件：データ、positive、候補、モデル、目的、比較法、seed
- 指標表：定義、単位、値域、primary / diagnostic、何を測り何を測らないか
- validationで決める事項、testの使用時点、代表選択規則、許容する品質低下
- 実行場所、コマンド、未使用の出力先、概算時間と資源、停止条件
- 完了条件と確認方法、reportの保存先
- 承認者、承認日、承認範囲、承認後の変更と理由
- 中断時の引き継ぎ：完了したこと、残り、次に読むファイル

内部計画と外部の事前登録は区別する。
既にtestを見た条件はその事実を明記し、次の確認実験では未使用の評価対象をどう確保するか決める。
この入口の作成は、新しい実験の実行許可ではない。
